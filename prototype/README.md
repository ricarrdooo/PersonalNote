# 拾页 · 交互原型

双击 `index.html`，使用 Chrome 或 Edge 打开即可。原型不需要安装依赖或连接网络。

可以试用：

- 笔记本、收藏、收集箱和回收站之间切换。
- 创建、编辑、搜索、收藏笔记，删除后恢复。
- 新建今日日记，从日记、阅读、会议和项目模板创建笔记。
- 点击正文下方“添加内容块”或输入 `/`，插入标题、待办、引用等。
- 在偏好设置中切换深浅主题、字号、正文宽度和强调色。
- 切换专注模式、查看文章大纲、导出 Markdown。

编辑内容和偏好保存在当前浏览器的本地存储中；清除浏览器数据会移除这些内容。这是用于确认视觉与交互的网页原型，正式桌面版的数据存储将独立实现。

`preview-light.png` 和 `preview-dark.png` 是对应主题的实际界面截图。

`verify-prototype.py` 是开发验证脚本，使用本机现有 Chrome 与 Python Playwright；`.qa-browser/` 是独立的验证浏览器运行目录。
