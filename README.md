# 拾页 Shiye

本地优先的 C++ / Qt 桌面电子笔记。左侧采用分级文件夹目录，支持笔记正文、图片、视频和其他附件。

## 启动

双击项目根目录的 **打开拾页.cmd**。Windows 桌面程序位于 `dist/Shiye/Shiye.exe`，已附带 Qt 与编译器运行库。

启动脚本将资料保存在项目根目录的 `data/` 中。直接启动 exe 时，默认使用 exe 同级的 `data/`；需要指定资料库时运行：

```powershell
.\dist\Shiye\Shiye.exe --data-dir F:\MyNotes
```

同一个资料库同时只允许一个窗口打开。

## 使用

- **分级目录**：点击新建笔记旁的文件夹按钮建立目录；右键新建子目录、重命名、移动、收藏或移入回收站。支持拖动目录和笔记整理层级，禁止循环嵌套。
- **编辑**：自动保存；Ctrl+S 立即保存。工具栏提供标题、列表、待办、引用、代码、加粗、斜体和撤销重做。空行输入 `/` 插入内容块；待办前的方框可点击切换，也可按 Ctrl+Enter。
- **图片**：点击“图片”、拖入文件或粘贴剪贴板图片，内嵌到正文。图片默认居中、保持比例，插入后可直接续写正文；旧笔记的图片间距会在打开时修正。单击图片显示尺寸、对齐、预览和移除操作，双击进入可缩放的预览窗口。正文内移除图片支持撤销，原始副本仍可从“附件”中找回。
- **视频**：点击“视频”或拖入文件。点击正文中的视频条目，或双击下方附件列表打开播放窗口。支持播放暂停、进度、音量和系统播放器入口。应用内可播放的编码取决于 Windows 已安装的解码器。
- **搜索**：按 Ctrl+Shift+F 搜索标题和正文，支持中文关键词。
- **文内查找与替换**：Ctrl+F 查找当前正文，Ctrl+H 展开替换；Enter / F3 下一处，Shift+F3 上一处，Esc 关闭。支持区分大小写、全字匹配、首尾循环，代码块和表格中的文字也可查找。全部替换会先保存当前版本，替换后可用 Ctrl+Z 一次撤销；回收站中的笔记只允许查找。
- **Markdown 导入**：顶部 `… → 导入 Markdown 文件`、Ctrl+Shift+I，或将 `.md` / `.markdown` 文件拖入编辑区。每个文件建立一篇新笔记，按文件名命名，导入当前目录；支持多选。原始文件和本地图片、链接附件一起复制到资料库，原文件移走后仍可查看。网页链接可 Ctrl+单击或右键“打开链接”。
- **日记与模板**：今日日记按实际日期创建并复用；可从阅读、会议、项目模板创建笔记。
- **外观**：偏好设置支持深浅主题、字号和强调色；顶部可切换专注模式、查看文章大纲。
- **粘贴**：网页富文本保留标题、加粗等结构，并采用笔记的字体、底色和间距；Ctrl+Shift+V 粘贴为纯文本。代码块中的粘贴保持纯文本。
- **导出与备份**：顶部 `…` 菜单导出 Markdown / HTML，附件一并复制到相邻 `.assets` 文件夹；完整备份包含 SQLite 和全部附件。恢复会先验证备份，并保留恢复前的资料库副本。
- **历史版本**：顶部 `… → 笔记历史版本` 查看与恢复正文和标题。每次实际修改并保存时，上一版与新内容在同一事务中写入；恢复操作也会保留恢复前的版本。历史包含富文本、代码语言和图片引用，附件原件仍随资料库保存。旧笔记从升级后的第一次修改开始积累历史，历史目前不自动清理。
- **自动备份**：默认开启，启动后生成一份备份，之后每 30 分钟检查一次，有修改时再次备份；默认目录为 `data/backups/automatic/`。仅在新的备份校验成功后清理较早的自动备份，保留最近 10 份；手动备份和恢复前备份不参与清理。顶部显示最近成功时间或失败提示；在 `… → 数据保护与自动备份` 可修改位置、立即备份或检查资料库。
- **软件更新**：右上角“检查更新”或 `… → 软件更新`，默认源为公开仓库 `ricarrdooo/PersonalNote`。启动后自动检查（最多每 4 小时一次），有较新的正式 Release 时显示“可用更新”。下载后核对 SHA-256，点击“安装并重启”会先完整备份资料，退出程序后替换程序文件，再以原资料库路径启动。无需安装 Git 或 GitHub 插件。

## 发布程序更新

程序从 GitHub Releases 下载打包好的 Windows 64 位程序，不会自动运行仓库中的源码。单纯 push 代码不会提示更新；需要发布正式版本及两个更新附件。草稿、预发布和较旧版本不会安装。

1. 完成代码修改，把 `src/main.cpp` 的应用版本及 `CMakeLists.txt` 的工程版本同步提高，例如 `0.4.1`。
2. 运行 `scripts/package-release.ps1`，脚本会编译、部署并在 `build/releases/v版本号-时间/` 中生成 `Shiye-windows-x64.zip` 和 `Shiye-update.json`。
3. 在 <https://github.com/ricarrdooo/PersonalNote/releases/new> 发布正式 Release，tag 使用同一版本，例如 `v0.4.1`，上传上述两个文件。
4. 笔记端检查到更高版本后会显示提示；用户点击下载、安装即可更新。

更新包只包含程序文件，不包含 `data/`、正文数据库、附件和备份。安装器还会检查当前自定义资料库的实际路径，阻止写入。更新前的完整资料库保留在 `data/backups/pre-update-*`（或所选资料库对应目录）；旧程序保留在更新缓存的 `rollback/` 中。替换失败会尝试恢复旧程序；意外中断后，通过新的“打开拾页.cmd”启动会先进行恢复。程序放在无写入权限的目录时，会提示搬到可写位置后再更新。

0.3.0 及更早版本没有自动更新功能，需要先手动换成本轮 0.4.0 完整程序；此后才可通过应用更新。当前公开源不需要令牌；私有仓库和预发布渠道暂不支持。大型资料库的更新前完整备份可能耗时，完成备份前不会启动程序替换。

## 长期保存与恢复

自动保存会在停笔约 650 毫秒后执行；持续输入时每隔最多约 5 秒尝试保存，切换到其他应用或关闭窗口时也会保存。保存失败会明确提示并阻止切换笔记或正常关闭。尚未提交的输入法文字、突然断电前尚未成功保存的改动，仍可能丢失；历史版本保护的是已经成功保存的内容。

新版完整备份包含笔记、历史和所有附件的 SHA-256 校验清单，恢复前核对文件内容、数据库完整性和引用关系。文件损坏或附件丢失时会拒绝恢复，不覆盖当前资料。旧版备份仍支持原有的数据库和附件大小检查。恢复过程中中断，下次打开会先尝试回到恢复前资料；数据库缺失时不会悄悄建立空资料库。

**请在“数据保护与自动备份”中将备份目录设到另一块磁盘或外置硬盘。** 默认同盘备份能帮助找回误修改，无法覆盖整块磁盘损坏。外置盘断开或磁盘空间不足时，备份失败会显示在顶部；原备份会保留，可重新连接后点击“立即备份”。本版本每次复制并校验完整资料库，大量视频附件可能使备份耗时较长，期间会显示进度提示。

首次正式存放重要知识前，建议做一次恢复演练：创建完整备份；用 `Shiye.exe --data-dir F:\Shiye-Recovery-Test` 打开一个新的测试目录，再从菜单恢复备份，确认正文、历史与附件可读取。不要直接编辑唯一的备份副本。自动备份暂不提供云同步或多设备冲突合并。

资料库包含 `notes.sqlite`、`attachments/`、`preferences.ini`。请通过程序的“完整备份资料库”功能备份媒体与笔记。

## Markdown 文件兼容范围

导入支持 UTF-8（含 BOM），单文件最多 8 MB。标题、加粗、斜体、删除线、列表、待办、引用、代码块语言与空行、普通表格、图片和链接会转换为富文本。普通表格也可随 Markdown 导出；代码内容含有反引号时，会自动使用更长的围栏，避免代码被截断。

本地附件仅自动复制源 Markdown 所在目录及子目录中的文件；源目录外、缺失的文件和网络图片会保留地址并显示导入提示。每篇导入通过事务一起提交正文和附件索引，失败时撤回新笔记及本次复制的文件。原始 Markdown 始终作为成功导入笔记的附件保存，便于核对或重新处理复杂语法。

HTML 源码按文字显示，数学公式、图表语法和插件专用语法暂不提供专门渲染；嵌套复杂排版与原软件可能存在差异。需要保持完整富文本布局时，可导出 HTML 或制作完整资料库备份。

文内查找使用普通文字匹配；最多显示前 1000 处高亮。匹配超过 10000 处时，会提示缩小关键词并停用全部替换，避免仅替换一部分却误报完成。

## Markdown 快捷输入

在正文的行首输入标记，再按空格，当前段落会立即转换为富文本。标记会消失，后续直接输入内容即可。

| 输入 | 结果 |
| --- | --- |
| `# `、`## `、`### ` | 一级、二级、三级标题；同时支持到六级 |
| `- `、`* `、`+ ` | 项目列表 |
| `1. ` | 编号列表 |
| `[] `、`[ ] `、`[x] ` | 未完成或已完成的待办 |
| `> ` | 引用 |
| 三个反引号后按空格或回车 | 代码块 |
| 三个反引号后接 `python`、`cpp`、`js` 等语言名，再按回车 | 带语言的代码块 |
| `---` 或 `***` 后按空格或回车 | 分割线 |

行内支持 `**加粗**`、`*斜体*`、反引号包裹的行内代码、`~~删除线~~`，输入闭合标记后自动转换。

标题中按 Enter 会回到正文，Shift+Enter 在标题内换行。列表与待办按 Enter 继续下一项，空项再按 Enter 退出。代码块内保持字面语法，空代码行按 Esc 可返回正文。

代码块内按 Ctrl+Enter 可跳到块后的正文，方便接着插入图片或继续记录。

光标进入代码块后，上方显示“代码语言”和“复制代码”。可以选择 Python、C/C++、JavaScript、TypeScript、JSON、HTML、CSS、SQL、Bash 或纯文本，也可输入其他语言名称后按回车；已支持的语言提供基础语法高亮。语言设置作用于当前整个代码块，随笔记保存，Markdown 导出会保留语言标记和空行。在独立代码行输入三个反引号并按回车可结束代码块。

代码底色与语法颜色随深浅主题即时更新：白天使用浅灰蓝底，深色使用深蓝灰底。旧笔记中保存的固定代码颜色会在打开时迁移，切换主题不会改写代码内容或清除撤销记录。

工具栏提供 H1 / H2 / H3 按钮、明确的标题级别下拉项，并显示光标所在段落的格式。Ctrl+Alt+1/2/3 切换前三个标题级别，Ctrl+Alt+0 返回正文；Ctrl+B / Ctrl+I 加粗、斜体。

这些是 Markdown 输入快捷方式；正文以富文本保存，编辑区不会持续显示语法标记。

当前本机 Qt 5 DirectShow 的有效视频解码测试未通过，内置视频播放尚未验证成功；视频导入、保存和附件链接已通过验证，可以使用视频窗口里的“用系统播放器打开”。

## 构建

已在 Qt 5.12.12 / MinGW 7.3 64 位环境构建与验证。工程同时提供 qmake 和 Qt 5/6 CMake 配置；Qt 6 配置尚未在本机编译验证。

```powershell
.\scripts\build.ps1
# 其他 Qt / MinGW 安装位置：
.\scripts\build.ps1 -QtRoot C:\Qt\5.15.2\mingw81_64 -MinGWRoot C:\Qt\Tools\mingw810_64
```

也可用 Qt Creator 打开 `PersonalNote.pro`。所需模块：Widgets、Sql、Multimedia、MultimediaWidgets。

`prototype/` 保留最初的网页视觉原型；正式桌面程序不依赖浏览器，也不读取原型的浏览器本地存储。
